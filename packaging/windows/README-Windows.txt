Codex Token Observatory — Windows

Requirements:
- Node.js 18+
- Codex CLI for Codex data (optional for Pi-only use)
- pi is optional

Install:
1. Extract this ZIP to any folder.
2. Double-click start-observer.cmd.
3. The dashboard opens at http://127.0.0.1:4399.

The dashboard reads local Codex and pi session data only. Nothing is uploaded.
